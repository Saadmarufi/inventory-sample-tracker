# inventory-sample-tracker

Lightweight Python & Web utility for tracking sales sample inventory, stock levels, and reorder thresholds.

## Overview
This utility assists in managing stock levels for sales samples, automatically flagging items when stock falls below pre-configured reorder thresholds.

## Features
- Stock level monitoring for product samples
- Automatic reorder threshold alerts
- Flexible Python data structures for easy integration

## Usage
Run `tracker.py` using Python 3:
```bash
python tracker.py
```
